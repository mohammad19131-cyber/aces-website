# ABC XIV

Official frontend website for the Aitchison Business Concept, fourteenth edition.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Update event details

Edit `lib/site.ts`:

- `eventStartISO` — countdown target
- `eventDateLabel` — date shown in Event Information
- `registrationUrl` — registration link (leave empty until the form is ready)
- `eventFacts` — any additional confirmed information
